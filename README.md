# OJ 刷题记录

洛谷、蓝桥杯等在线评测平台的练习代码仓库。每一道题放进对应专题目录，方便日后复习和复试展示。

## 目录

```text
数组/          数组相关题
字符串/        字符串相关题
模拟与枚举/     模拟、枚举类题
数学/          数学计算类题
基础算法/       排序、二分、前缀和等基础算法题
```

## 提交规范

1. 文件名使用 `题目编号_题目名.cpp`，例如 `B2120_单词的长度.cpp`。
2. 每个文件开头写三段注释：

```cpp
// 题目：洛谷 B2120 单词的长度
// 思路：一次扫描，遇分隔符结算
// 复杂度：O(n)
```

3. 写完后必须提交并通过评测，才放进仓库。
